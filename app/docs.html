API and MCP

Use Coroner from code or from an agent.

Answers come from the open rule engine today. Every response says "engine": "rules" and "model": null. When the Coroner model is hosted, that field will say so. Risk classification from public on-chain data, not financial advice. Labels describe patterns consistent with the numbers, never accusations.

API v1

Base URL https://coronerai.pro/api/v1. No key, no account, CORS open, rate-limited per IP (HTTP 429 with Retry-After). Machine-readable: openapi.json.

EndpointWhat it does
GET /verdict/{address}Verdict from contract facts the server can read: owner, mint, blacklist, pause, proxy.
POST /verdictSame, plus market and holder facts you supply in ext (the server cannot read those sources).
POST /premortemPre-mortem of a launch draft: risks, death patterns, fixes.
GET /api/statsPublic daily usage counts (verdicts, pre-mortems, autopsies, Sentinel, waitlist) by source: web, API, MCP. Counts only.
POST /autopsyWhat happened to a token the open collector watched for 24 hours.

Example

curl https://coronerai.pro/api/v1/verdict/0x84bbcc13a9d92ee0a069b822929e7edcce300bfc

curl -X POST https://coronerai.pro/api/v1/premortem \
  -H "content-type: application/json" \
  -d '{"name":"Tacocat","symbol":"TACO","buyTaxPct":5,"sellTaxPct":10,"liquidityLock":"none","hasMint":true}'

Each answer has verdict (risk class, flags with evidence_ids, confidence), facts, notes and narrative, a plain-language reading written from the verdict that adds no new facts.

MCP server

Three tools for AI agents: check_token, premortem, autopsy_token. It reads market and holder data on your machine, then calls the API. Source and install steps: github.com/coroner-hash/ai/tree/main/mcp.

git clone https://github.com/coroner-hash/ai.git
cd ai/mcp && npm install
claude mcp add coroner -- node /absolute/path/to/ai/mcp/server.mjs

Models

coroner-31b (16-bit, Gemma 4 31B), coroner-31b-GGUF (4-bit, 18.7 GB, for llama.cpp; accuracy of this build not measured yet) and coroner-coder-7b (fixes scanner flags in ERC-20 source; narrow synthetic training data, always compile). All Apache-2.0.

Sentinel

Email alerts when a token's contract changes: owner, ownership renounced, mint, blacklist or pause appearing, proxy upgrade, supply. Double opt-in, three tokens per email, one-click unsubscribe. Contract changes only: market and liquidity alerts are not in this version. Sign up at /sentinel.

Narrator

Under every report on this site, and in the narrative field of the API, is a short reading in plain words. It is deterministic text built from the verdict's own flags and evidence, so it cannot introduce a number the verdict does not contain.

Coroner is independent and not affiliated with Robinhood. Preliminary and in development: fields may change before v1 is frozen.
